# Contributing

Bug reports and focused pull requests are welcome.

Before submitting a pull request:

1. Keep all user-facing text and documentation in English.
2. Never include Home Assistant access tokens, private URLs, or diagnostic data
   that identifies a home network.
3. Run `make validate`.
4. Explain the behavior change and how it was tested.

Please keep the extension small and avoid runtime dependencies beyond the GNOME
platform.
